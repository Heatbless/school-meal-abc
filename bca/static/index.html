How this discrete bee algorithm works

1 · Employed bees

Each bee tries one meal component substitution in its own five-day schedule, guided by a distinct partner source. Only a strictly lower score is accepted.

2 · Onlookers

Fitness is 1 / (1 + score). A host-generated random draw selects a source with probability fitness / total fitness, then tries a substitution.

3 · Scouts & memory

After the failure limit, scouts replace a source with a fresh random schedule. Best-ever memory remains. Stop at the cycle limit, patience limit, or user request.

Score = weighted normalized cost + budget excess + nutrition deviations + repetition + workload excess. Nutrition is per serving; cost, ingredients, and batch workload scale to the school.

Costs, nutrition values, and targets are editable demonstration inputs. This is a discrete ABC teaching adaptation. A best observed schedule is not a guarantee of a global optimum.
